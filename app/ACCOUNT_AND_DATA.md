# Account and Data Self-Service

Organizations must be able to manage their account and data without product-owner intervention.

## Data Export

Authorized administrators can export organization data.

Supported formats should include:

- CSV
- JSON

Exports must respect permissions and organization isolation.

## Export Scope

Administrators should be able to export:

- Clients
- Properties
- Units
- Services
- Appointments
- Resources
- Teams
- Eligibility
- Funding
- Audit history
- Configuration

## Account Management

Organizations should be able to manage:

- Organization information
- Administrators
- Users
- Subscription
- Payment method
- Billing information
- Invoices

## Subscription

Organizations should be able to:

- Select a plan
- Upgrade
- Downgrade
- Update payment information
- View invoices
- Cancel

## Cancellation

Cancellation should clearly explain:

- Effective date
- Data retention period
- Export options
- Reactivation options if available

## Data Retention

Data retention rules must be clearly defined and enforced automatically.

## Account Recovery

Authorized administrators must have secure account recovery options.

## Organization Closure

Closing an organization must use a controlled process.

The system must prevent accidental deletion.

Administrators should receive clear warnings and confirmation before irreversible actions.

## Product Owner Independence

Normal account, billing, export, and cancellation operations must not require product-owner involvement.
