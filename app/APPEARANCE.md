# Appearance

The application must support three appearance modes:

- Light
- Dark
- System

## System Mode

When System is selected, the application follows the user's device or operating-system appearance setting.

## User Preference

Users may choose their preferred appearance independently.

The preference should persist between sessions.

## Organization Defaults

Administrators may optionally define the organization's default appearance.

A user's explicit preference takes priority over the organization default.

## Design Direction

The product uses a hybrid visual style:

- Modern SaaS
- Practical operations interface
- Clean and professional
- Strong visual hierarchy
- Clear scheduling information
- Accessible status indicators
- Responsive layouts
- Minimal visual clutter

## Scheduler

The scheduler should prioritize operational clarity.

The calendar should make it easy to distinguish:

- Appointments
- Travel time
- Availability
- Conflicts
- Holds
- Team assignments
- Resource assignments
- Changes caused by schedule ripple

## Accessibility

Light and dark themes must maintain readable contrast and clear status indicators.

Information must never depend solely on color.
